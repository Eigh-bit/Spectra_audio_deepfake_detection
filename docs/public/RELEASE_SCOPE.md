# 公开版收录范围

本次整理将公开源码选择与完整私有研究工作区分开。原件、日志、报告、数据和交付包都在本地保留；只改变README、说明和Git收录规则，不修改冻结推理源码，也不删除资源。

公开选择采用`.gitignore`白名单：根README/LICENSE/NOTICE、`docs/public/`、`reports/public/`、三版源码快照的本项目推理模块/配置/依赖锁，以及公开文件SHA清单。白名单以外的新目录/文件默认不收录；已批准路径中的新增源码或说明也须在发布前审查。

明确不收录：官方比赛手册/说明/示例run.py、平台账号与操作档案、目标音频和逐条预测/伪标签、目标域学习gate、全部数据/权重、上游模型实现/模型卡、完整实验run与内部报告/工作区导航、历史私有上传清单和清理元数据。通用配置中的资源路径/SHA只用于识别，不包含原音频或授权这些权重发布。

完整内部报告不改写成另一份“最新版”；[公开研究说明](../../reports/public/RESEARCH_OVERVIEW.md)仅介绍方法与局限，不替代内部权威实验报告。公开选择不提供可核验的官方比赛成绩。

公开收录范围仅限上述源码与文档，完整工作区不随此选择发布。已排除第三方及比赛原始资源，但仍需所有者在实际发布前确认原创部分的权利归属及比赛允许公开的方法范围。MIT已由用户明确选择，不能据此称未提供的研究权重/完整训练流程已可公开复现。

私有归档规则与旧README/文件清单备存在本地`reports/assets/public_prepare_20261101_01/`，不随公开选择上传。公开源码仓库不能代替模型/数据/完整实验的独立备份；不得据此删除整个工作区。
